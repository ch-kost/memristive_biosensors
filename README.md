Проект позволяет работать с паспортами мемристивого биосенсора.

## Запуск

Требуется Python 3.11 или новее.

```bash
python -m pip install -e '.[dev]'
biosensors add BS-001 TiO2 1250
biosensors list
```

## Проверки

```bash
ruff check src tests
python -m unittest discover -s tests -v
```

## Процесс разработки

Изменения готовятся в отдельных ветках, созданных от `dev`.
Pull Request направляется в `dev`; затем GitHub Actions автоматически запускает
статический анализ и модульные тесты на Python 3.11 и 3.12.
Текстовые отчёты сохраняются в артефактах запуска на 30 дней.
Ошибка линтера или теста делает соответствующую проверку неуспешной.

Ветка `main` предназначена для проверенных изменений после проверки `dev`.
